# 从云端薄壳拉取任务卡（给任何 Agent 用）

> 位置：`_系统迭代\交接仓库\拉取云端任务卡.ps1`
> 作用：登录云端 → 取「待执行」任务卡 → 落到本地 `50_解决区\任务卡\` → 追加登记到 `_系统迭代\待执行任务卡.md`
> 特性：**只读云端**，只写本地；不写服务器、不改卡片状态。

## 一键用法

```powershell
pwsh -File "C:\Users\Vansinver\Desktop\信息抓取\_系统迭代\交接仓库\拉取云端任务卡.ps1"
```

- 默认只拉 `待执行`（pending）。要拉全部（含已完成/已验收）：加 `-Only all`
- 输出会列出：拉到几张、哪些是新增、写到哪

## 手工调用（不用脚本时）

基站：`http://47.97.204.93`（HTTP，无域名）

1. 登录取 token
```powershell
$r = Invoke-RestMethod "http://47.97.204.93/api/login" -Method Post `
  -Body (@{username="vansinver";password="<见 _雷达\.env 的 OWNER_PASSWORD>"}|ConvertTo-Json) `
  -ContentType "application/json"
$h = @{ Authorization = "Bearer $($r.token)" }
```
2. 看待执行队列
```powershell
Invoke-RestMethod "http://47.97.204.93/api/taskcards/pending" -Headers $h
```
3. 下载某张卡的原文（用 JSON 接口的 `md` 字段）
```powershell
Invoke-RestMethod "http://47.97.204.93/api/taskcards/<卡名>" -Headers $h |
  Select-Object -ExpandProperty md
```

> 注：`/api/taskcards/<name>/export` 在**中文文件名**上会 500（响应头 Content-Disposition 不能编码非 ASCII）。脚本已绕开，改用 JSON 接口；若有人要修，改成 RFC5987 的 `filename*=UTF-8''...`。

## 接口表

| 方法 | 路径 | 谁可调 | 作用 |
|---|---|---|---|
| POST | `/api/login` | 任何人 | 用户名+密码 → 7 天 JWT |
| GET | `/api/taskcards/pending` | owner | 待执行+执行中 清单 |
| GET | `/api/taskcards` | owner | 全部卡（含状态/时间） |
| GET | `/api/taskcards/<name>` | owner | 单卡 HTML+MD |
| GET | `/api/taskcards/<name>/export` | owner | 单卡 .md 下载（**中文名会 500**，用上一行的 `md` 字段代替） |
| POST | `/api/taskcards/<name>/claim` | owner | 置 `执行中`（body `{"agent":"..."}`） |
| POST | `/api/taskcards/<name>/writeback` | owner | 回写（body `{"status":"已完成","record":"..."}`） |

状态可选：`执行中 / 已完成 / 已验收 / 受阻`

## 认证与密码

- 用户名：`vansinver`
- 密码：本机 `信息抓取\_雷达\.env` 的 `OWNER_PASSWORD` 行（**脚本自己读，不用手填**）
- 约束：密码不进仓库、不进聊天、不进任何公开页面；JWT 7 天后过期，重跑脚本即可

## 已知限制（重要）

1. **云端不会自动写你的 Obsidian**。云同步是 `local-disk` 模式，`cloud.push()` 不生效；所以“点了生成任务卡”只落在服务器 `/data/taskcards/` + 服务器上的 `_inbox.md`。
2. 本机 Agent **必须主动拉取**（跑本脚本或调接口），不存在“自动出现在本地 inbox”。
3. 游客（未登录）只能看到 1 份虚构示例，看不到真实卡。
4. 接口是 HTTP，token 明文传输；不要在不信任的网络里长期用。

## 红线

- 拉卡是只读操作；`claim` / `writeback` 会改云端状态，**回写前先让用户确认**。
- 卡内可能含真实项目信息，不要整卡贴到公开仓库或聊天。
- 不要把 `OWNER_PASSWORD`、`DEEPSEEK_API_KEY` 写进任何会被提交的文件。
