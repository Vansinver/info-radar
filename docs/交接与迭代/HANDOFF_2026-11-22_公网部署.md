## 1. 架构（单机同源）
```
浏览器 → http://47.97.204.93/ → uvicorn(FastAPI server:app, :80)
         ├─ 静态前端(同源挂载 /)
         ├─ JWT 认证(owner / guest)
         ├─ 数据 /data (reports/discussions/solutions/taskcards/legacy)
         ├─ 任务 jobs.sqlite3 (running→重启标 interrupted)
         └─ 持久化 local-disk
```
优点：一个 URL 同时给前端+API；免 GitHub Pages、免 CORS 跨域凭证、按 IP 访问无需备案。

## 3. 服务器内部（给有权限的运维者）
| 用途 | 路径 |
|---|---|

## 4. ★ 怎么改 UI
1. 改仓库 `frontend/*`（有权限者提交）。
2. 有服务器权限者执行：`bash /opt/info-radar/redeploy.sh`。
3. 打开 http://47.97.204.93/ 验证。

约束：`config.js` 的 `API_BASE` 保持空串（同源）；不得依赖本机地址。改前端不影响数据。
