## 1. 架构（单机同源）
```
浏览器 → http://47.97.204.93/ → uvicorn(FastAPI server:app, :80)
         ├─ 静态前端(同源挂载 /)
         ├─ JWT 认证(owner / guest)
         ├─ 数据 /data (reports/discussions/solutions/taskcards/legacy)
         ├─ 任务 jobs.sqlite3 (running→重启标 interrupted)
         ├─ E1 引擎 /opt/info-radar/venv-gptr (gpt-researcher + deepseek retriever)
         └─ 持久化 local-disk
```
优点：一个 URL 同时给前端+API；免 GitHub Pages、免 CORS 跨域凭证、按 IP 访问无需备案。

## 4. ★ 怎么改 UI
1. 改仓库 `frontend/*`（有权限者提交）。
2. 有服务器权限者执行：`bash /opt/info-radar/redeploy.sh`。
3. 打开 http://47.97.204.93/ 验证。
约束：`config.js` 的 `API_BASE` 保持空串（同源）；不得依赖本机地址。改前端不影响数据。
## 4b. 怎么跑 E1（研究/报告引擎）
- 唯一入口：登录 owner 后 `POST /api/jobs/e1`，body `{"query":"...","session_id":"可选"}` → 返回 `job_id`。
- 后端以 `/opt/info-radar/venv-gptr/bin/python run_e1.py <query>` 起子进程，日志 `/data/joblogs/<job_id>.log`。
- 产物：`/data/reports/YYYYMMDD_HHMM_<标题>.md`（含“## 来源清单”）。
- 环境变量：`RETRIEVER=deepseek`、`FAST_LLM/SMART_LLM=deepseek:deepseek-flash`。
- 实测：单问约 20–60s，成本约 ¥0.1–0.2，2G 内存可跑（used≈680MB + swap）。
